# Week 03: Exploratory Data Analysis and Visualization

## Project Overview
This project explores a fictional Nigerian retail orders dataset using Python.

The objective is to understand the dataset, identify patterns, investigate missing values and potential outliers, and communicate findings through statistical summaries and visualizations.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Description
The dataset contains 12 observations and 6 variables:

- order_id
- city
- channel
- order_value
- delivery_days
- age

The dataset is fictional and was reproduced from the Week 03 EDA learning guide.

## Analysis Performed
- Data inspection and quality assessment
- Missing value analysis
- Descriptive statistics
- Grouped analysis
- Outlier investigation
- Distribution analysis
- Correlation analysis
- Data visualization

## Visualizations
The project includes:
- Histogram
- Box plot
- Bar chart
- Scatter plot
- Correlation heatmap

## Limitations
The dataset is small and fictional. Therefore, findings should not be generalized to the entire Nigerian retail industry.

## How to Run
1. Install the required libraries using requirements.txt.
2. Open the Jupyter Notebook.
3. Run all cells from beginning to end.

## Conclusion
The project demonstrates the use of exploratory data analysis techniques to inspect, summarize, visualize and interpret data.
